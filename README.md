## 📖 Overview

SWASAKESARI is a full-stack Ayurvedic e-commerce web application designed to help users discover and purchase authentic Ayurvedic products online. The platform provides secure authentication, online payments, order management, and an admin dashboard to manage products and users.

This project was developed as a learning project to gain hands-on experience in full-stack web development, API integration, authentication, and database management.

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/VenkataChandu-M/SWASAKESARI.git
```

### Go into the project

```bash
cd SWASAKESARI
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Configure Environment Variables

Create a `.env` file:

```env
SECRET_KEY=your_secret_key
JWT_SECRET_KEY=your_jwt_secret

RAZORPAY_KEY_ID=your_key
RAZORPAY_KEY_SECRET=your_secret

SHIPROCKET_EMAIL=your_email
SHIPROCKET_PASSWORD=your_password
```

### Run the application

```bash
python app.py
```
